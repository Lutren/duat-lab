# duat-lab

Synthetic DUAT laboratory skeleton for residue, calibration, event-store and artifact-memory experiments.

Status: `PUBLIC_GITHUB_RESEARCH_BOUNDARY`.

`duat-lab` is where speculative models become falsifiable demos. It is not a
claim that DUAT proves physics, medicine, consciousness or social prediction.
It is a public-safe lab for asking:

> What would make this agent action or research model fail?

## What This Includes

- Provides a synthetic lab pattern for observer-state experiments.
- Separates event logging from artifact promotion.
- Documents residue, calibration and falsifier boundaries.
- Includes a complete synthetic review demo where an agent draft is blocked for
  missing sources and routed to human review.

## Demo: Agent Review Gate

The first demo is intentionally practical:

1. an agent drafts a high-impact report-like answer;
2. the draft has no verified sources;
3. the gate returns `REVIEW`;
4. the witness log explains what evidence is missing;
5. the final report stays unpublished until sources and review exist.
